# wrotron.github.io

Website for Wrotron — smart, cashless vending machines for workplaces across India. Served at https://wrotron.in via GitHub Pages.

- `index.html` — page markup
- `styles.css` — styles
- `scripts.js` — interactions and the enquiry form (Firestore `vending_leads`)
- `assets/favicon.svg` — icon
