# wrotron.github.io

Website for Wrotron: smart, cashless vending machines for workplaces across India. Served at https://wrotron.in via GitHub Pages.

- `index.html`: page markup
- `styles.css`: styles (navy/cream palette, single orange accent for actions)
- `scripts.js`: interactions and the enquiry form (Firestore `vending_leads`, WhatsApp fallback)
- `credits.html`: attribution for the openly licensed photos
- `assets/photos/`: photos in WebP and JPEG, each with a small (`-sm`, 800px) and a large version; `credits.json` records source, author and licence
- `assets/favicon.svg`: icon

Photos come from Wikimedia Commons under CC0, CC BY or CC BY-SA licences. If you replace one, update `credits.json` and `credits.html`.
